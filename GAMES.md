# Kids Learning Website - Games Summary

## 0-2 Years (4 games)
1. **Animal Sounds** 🐶 - Tap animals to hear their sounds
2. **Learn Colors** 🎨 - Tap colors to learn their names
3. **Learn Shapes** 🔷 - Tap shapes to learn their names
4. **Story Time** 📚 - Read simple stories with pictures

## 2-5 Years (4 games)
1. **Find Alphabets** 🔤 - Find the target letter from a grid
2. **Find Numbers** 🔢 - Find the target number from a grid
3. **Trace Letters** ✏️ - Practice tracing letters of the alphabet
4. **Build Words** 🔤 - Build simple 3-letter words from scrambled letters

## 5+ Years (3 games)
1. **Read Stories** 📖 - Read stories and answer comprehension questions
2. **Spell Words** ✍️ - Spell words based on hints
3. **Math Challenge** 🔢 - Solve addition and subtraction problems

## Tech Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## To Run
```bash
cd kids-learning-next
npm run dev
```

Visit http://localhost:3000
